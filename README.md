Maze Solver
- Ứng dụng giải mê cung bằng Python sử dụng các thuật toán tìm kiếm:

  + BFS (Breadth First Search)
  + DFS (Depth First Search)
  + UCS (Uniform Cost Search)
  + Greedy Best First Search
  + A* Search

- Tính năng
  + Hiển thị mê cung bằng Tkinter
  + Chọn thuật toán từ giao diện
  + Hiển thị các nút đã duyệt
  + Hiển thị đường đi tìm được
  + So sánh số lượng nút đã khám phá

- Công nghệ sử dụng
  + Python 3
  + Tkinter
  + collections.deque
  + heapq

- Cách chạy
  + python "Maze Solver.py"

- Các thuật toán
Thuật toán	Tìm đường ngắn nhất
+ BFS	    Có
+ DFS	    Không đảm bảo
+ UCS	    Có
+ Greedy	Không đảm bảo
+ A*	    Có
